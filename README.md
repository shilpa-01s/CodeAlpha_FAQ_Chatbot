# FAQ Chatbot

This is a simple AI-based FAQ chatbot built using Python.

## Features
- Answers predefined questions
- Uses NLP (TF-IDF + cosine similarity)
- Simple GUI interface

## Technologies Used
- Python
- Tkinter
- Scikit-learn

## How to Run
1. Install dependencies:
   pip install scikit-learn

2. Run:
   python faq_chatbot.py
